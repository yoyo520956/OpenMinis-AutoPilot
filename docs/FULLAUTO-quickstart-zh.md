# 全自动模式 · 快速上手（中文）

> 适用：Minis AutoPilot v0.1.2+ / Applies to: Minis AutoPilot v0.1.2+

## 一、它是什么？

**全自动模式（Full-Auto）** 让 AI 像 OpenAI Codex 一样**连续自主工作**：读代码 → 改文件 → 跑命令 → 看报错 → 自我修复 → **直到任务完成**——全程不需要你一步步点"继续"。

## 二、怎么开启

1. 打开一个对话，在**输入栏底部的一排按钮**里找到「**⚡ 全自动**」
2. 点击点亮它（按钮高亮，并显示轮次角标）
3. 正常发送你的任务描述（写得越具体越好）
4. 之后就交给它**自动一轮接一轮地干**——角标会显示当前跑到第几轮

## 三、怎么停止

- 随时点**停止**（发送按钮会变成停止），立即中止
- 任务完成、或确实需要你决策时，它也会**自动停下并汇报**

## 四、内置安全护栏

- **20 轮预算**：最多连续跑 20 轮，防止失控
- **循环检测**：反复无进展时自动停止
- **受阻汇报**：需要只有你才有的东西（密钥、决策）时，停下等你

## 五、使用建议

- 任务描述给足上下文（「把这 3 个文件的接口统一成……」胜过「优化代码」）
- 大任务拆成里程碑更稳
- 中途发现方向不对：直接停止 → 补充说明 → 重新发送
- 它会留下完整的工作过程记录，随时可以回看

## 六、常见问题

- **开了没反应？** 确认消息已发送；若到达护栏上限自动停止，属正常（重发即可续做）
- **会和普通对话冲突吗？** 不会，开关按对话独立记录
- **能中途干预吗？** 可以——停止后修改你的要求，再发一条即可
