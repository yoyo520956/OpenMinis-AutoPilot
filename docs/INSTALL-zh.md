# Minis AutoPilot 安装指引（中文 · 保姆级）

> 适用：在 iPhone 上安装「Minis AutoPilot」（OpenMinis·全自动模式版）
> 最新版本：**v0.1.2** —— 已修复"打开即闪退"问题

---

## 一、下载哪个文件？

| 文件 | 用途 | 大小 |
|---|---|---|
| `OpenMinis-AutoPilot-v0.1.2-unsigned.ipa` | **主推** · 完整版 | 74.2 MB |
| `OpenMinis-AutoPilot-v0.1.2-lite-unsigned.ipa` | 备用 · 精简版（无小组件/分享扩展） | 72.3 MB |

> 建议先用**完整版**；如果签名工具对完整版报"扩展相关错误"，改换**精简版**再签。

📥 下载页：`https://github.com/yoyo520956/OpenMinis-AutoPilot/releases` （选 `v0.1.2` 的两个 ipa 文件即可）

## 二、安装步骤（沿用你现有的签名工具流程）

1. 把上面的 **.ipa 文件**保存到手机（存到「文件」App，或直接导入你的签名工具）
2. 打开你之前用的签名工具
3. 导入 ipa → 选择证书 → 签名 → 安装
4. 安装完成后**先别急着打开** → 先做下一步「信任证书」

## 三、⚠️ 信任证书（很重要！漏了这一步打开就会闪退）

装了新 App 或重签之后，**首次打开前**需要信任一次：

1. 打开 iPhone「**设置**」
2. 进入「**通用**」→「**VPN与设备管理**」
3. 找到你的开发者证书（名字和你签名时用的证书一致）
4. 点进去 → 点「**信任**」→ 弹窗确认
5. 然后再打开 App —— 应该就能正常进入了 ✨

> 什么时候需要"重新信任"：重装了 App、换了证书后。付费开发者证书（你这种）**不需要**每 7 天重签；只有免费证书才有 7 天限制。

## 四、怎么确认装的是"修复版"？

- 文件名带 **`v0.1.2`** 的就是修复版
- App 显示名：**Minis AutoPilot**（可与官方版共存，不会互相覆盖）

## 五、如果还是闪退怎么办？（排查顺序）

1. **先检查「信任证书」做了没有** —— 大多数"打开即闪退"是这一步没做
2. 换 **lite 精简版** 再签一次试试
3. 还是不行 → 把现象告诉我（打开瞬间黑白屏？弹窗？），我继续分析

## 六、进阶：让证书"直接签好"的版本（可选）

如果你想拿到**用你的证书签好、开箱即装**的版本（省去签名工具步骤）——
需要你确认一次：把你的证书**加密上传**到构建仓库（仅构建时使用，随时可删除）。
你回来说一声「**用**」即可，几分钟就能出包。
